# المرحلة 18أ — واجهة ومراجعة مرتجعات المشتريات

التاريخ: 2026-10-02. التنفيذ محلي، غير منشور. المرجع 01 في فهرس الصور.

## ما اكتمل

- استبدال الحفظ القديم المتفرق بنموذج مراجعة واضح؛ زر الحفظ معطل حتى تنفيذ 18ب.
- قائمة المرتجعات مع البحث والمورد والفاتورة والحالة والقيمة بعملة الفاتورة المرتبطة. العملة غير المعروفة معلمة صراحة.
- اختيار المورد ثم فاتورة مكتملة، دون اختيار تلقائي. الفاتورة الأصلية إلزامية لمراجعة السعر والكميات.
- حساب المتبقي بعد المرتجعات المكتملة المرتبطة؛ المخزون المتاح يطرح المحجوز. الحد هو الأقل من المتبقي والمتاح للأصناف المتتبعة.
- عرض تكلفة الفاتورة بعد خصمها النسبي، ورفض المنتج المحذوف أو المكرر، والتاريخ غير الصحيح أو السابق للفاتورة، والكمية الزائدة والكسرية للصنف المتتبع، والسبب الفارغ.
- تخفيض حساب المورد أو استرداد نقدي خيارات مقترحة فقط. رسالة المراجعة تؤكد عدم حفظ سند وعدم تغيير الأرصدة.
- قراءة عناصر الفواتير والمرتجعات على دفعات مستقلة لتجنب اقتصاص العناصر المتداخلة عند حد الاستعلام.

## التحقق

- `node --test tests/purchase-return-review.test.cjs`: ثلاثة اختبارات ناجحة.
- `npm run build`: ناجح، ويشمل فحص الأنواع.
- معاينة المتصفح: اختيار فاتورة شراء 5 وحدات، المتاح بعد الحجز 3، تكلفة صافية 18؛ مراجعة وحدتين تعطي 36 ILS دون كتابة مالية.
- هاتف 390×844: عرض المستند 390، لا تجاوز أفقي للصفحة؛ جدول الأصناف يتمرر داخلياً.
- صور: purchase-returns-desktop.jpg وpurchase-returns-mobile.jpg.
- فحص للقراءة فقط على قاعدة المشروع: نجحت علاقات عناصر المرتجعات والفواتير وحقول المخزون والحجز.
- لا معاملات تجريبية ولا تعديل قاعدة بيانات في هذه المرحلة.

## القيود ونقطة الاستكمال

هذه مراجعة وليست اعتماداً محاسبياً. الأسعار تقريب مبدئي لوحدة بعد الخصم، ويلزم توزيع دقيق للكسور على مبالغ الأسطر عند الحفظ. الفواتير الضريبية موقوفة في المراجعة إلى حين دعم تسويتها. المرتجعات القديمة غير المرتبطة لا يمكن نسبتها تلقائياً إلى فاتورة. قائمة الوثائق بلا ترقيم صفحات حالياً، وطباعة المرتجعات القديمة لم تتغير. المخزون المعروض لقطة قراءة؛ التحقق النهائي يجب أن يعاد داخل معاملة مقفلة.

التالي 18ب: حفظ ذري مرتبط بالفاتورة وسطرها، صلاحيات المتجر، أقفال تمنع التكرار وتجاوز الكميات، هوية طلب لإعادة المحاولة، تحديث المخزون وحساب المورد والقيد، وسند قبض وحركة صندوق للاسترداد النقدي عند توفر الصلاحيات. اختبارات تراجع كامل عند فشل أي أثر، وعدم إعادة الأثر المالي عند إعادة الطلب. لا تستخدم منطق تصفير المخزون لإخفاء عجز الكمية.
