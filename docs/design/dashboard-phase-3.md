# بازاركو — المرحلة الثالثة: لوحة التحكم المبسطة

## السلوك

- صفحة رئيسية فاتحة وقائمة جانبية كحلية، مؤشرات اليوم، إجراءات مباشرة، أحدث خمسة طلبات، وخطوات تجهيز المتجر.
- العرض المبسط هو الافتراضي للحساب المجاني الذي لم يحفظ اختياراً آخر. يحترم `settings.dashboard_mode` المحفوظ أثناء التسجيل؛ لا يغيّر خطة الاشتراك أو صلاحيات المستخدم.
- الأدوات المتقدمة متاحة عبر `/dashboard?view=advanced`، مع رابط للعودة إلى العرض المبسط. الصفحات التشغيلية الحالية تبقى متاحة من القائمة المبسطة.
- زر تسجيل المصروف يفتح نموذج سند الصرف الحالي مصنفاً «مصاريف تشغيل»، مع مستفيد يدوي وتاريخ اليوم في فلسطين.
- نسخ الرابط لا يرسل رسالة لأي شخص. يُحفظ اكتمال خطوة النسخ ضمن إعدادات المتجر عبر إجراء خادمي يتحقق من الجلسة والعضوية ويخضع لصلاحيات قاعدة البيانات. إذا تعذر الحفظ، يبقى الرابط منسوخاً وتظهر رسالة واضحة.

## معنى المؤشرات

- طلبات تحتاج متابعة: pending / confirmed / processing / ready / shipped، لجميع الأيام.
- مبيعات اليوم: إجمالي الفواتير غير المسودة وغير الملغاة الصادرة اليوم، مضافاً إليه إجمالي الطلبات المؤكدة أو الجاري تجهيزها أو شحنها أو المسلّمة المنشأة اليوم والتي لا ترتبط بفاتورة صادرة. يمنع احتساب الطلب والفاتورة المرتبطة به مرتين. هذا إجمالي قيمة المبيعات المسجلة، وليس تقرير صافي الأرباح أو صافي المردودات.
- مبالغ لم تُقبض: المتبقي غير السالب على الفواتير الصادرة والطلبات المؤكدة دون تكرار الطلبات المرتبطة بالفواتير، لجميع الأيام.
- مصاريف اليوم: سندات الصرف المصنفة اليوم، باستثناء تصنيف «مشتريات» والسندات المرتبطة بمورد أو فاتورة شراء. سند غير مصنّف لا يدخل هذا المؤشر.
- جميع الاستعلامات مقيدة بالمتجر الحالي، مع ترقيم الصفحات للبيانات المالية حتى لا تُقطع المجاميع عند حد Supabase الافتراضي.
- يُحسب اليوم في `Asia/Hebron`، وتستخدم قائمة الطلبات نفس حدود اليوم. فشل الاستعلام يظهر «—» وتنبيهاً بدلاً من صفر.

## التحقق

- نجحت أربعة اختبارات للمؤشرات: ارتباط الطلب بالفاتورة، المتبقي والسداد الزائد، فاتورة مرتبطة بتاريخ آخر، حدود اليوم وخيارات العرض.
- نجح TypeScript والبناء الإنتاجي، بما فيه lint.
- نجحت جميع استعلامات اللوحة في فحص قراءة فقط على متجر موجود بقاعدة المشروع باستخدام اتصال خادمي إداري. لم تُطبع بيانات شخصية أو أرقام مالية ولم تعدل سجلات.
- فُحصت معاينة سطح المكتب والهاتف بعرض 390px، بدون تمرير أفقي، بما فيها القائمة الجانبية، نسخ الرابط، والطلبات الفارغة وتعذر التحميل.
- أكد فحص HTTP أن مسار المعاينة يرجع 404 في بناء الإنتاج. المعاينة تستخدم بيانات توضيحية صريحة، ومتاحة في التطوير فقط. لا تستدعي عملية حفظ خطوة النسخ.
- لم يُختبر حفظ خطوة النسخ أو إنشاء سند مصروف بجلسة مستخدم فعلية؛ صلاحيات RLS أثناء الاستخدام الفعلي ليست مثبتة بفحص الاتصال الإداري.
- التعديلات محلية ولم تُنشر.
