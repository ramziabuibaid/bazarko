# المرحلة الرابعة: لوحة العمليات المتقدمة

طُوّرت الصفحة المتقدمة في /dashboard (أو ?view=advanced للحساب البسيط) إلى عمليات سريعة، حركة اليوم، رصيد الصندوق، المتابعات، رابط المتجر، وإعداد قابل للطي. تبقى شاشة المشروع المنزلي البسيطة كما هي.

- مبيعات اليوم تعيد استخدام حساب الفواتير الصادرة والطلبات المؤكدة دون تكرار، وفق يوم فلسطين.
- المقبوضات والمدفوعات: مجموع سندات اليوم بكل طرق الدفع.
- الرصيد: الحساب المرتبط بالصندوق الافتراضي النشط؛ لا تنشئ قراءة الصفحة صندوقاً أو حساباً. الرصيد المفقود يظهر غير متاح.
- المخزون: الأصناف النشطة عند حد التنبيه أو أدناه. الشيكات: المحفظة من اليوم إلى تاريخ اليوم +7 أيام.
- المستحقات تشمل الفواتير والطلبات المؤكدة غير المكررة. رابط التنبيه يفتح قائمة الفواتير؛ الطلبات المستقلة تبقى في قائمة الطلبات.
- اكتمال أول فاتورة يفحص تاريخ المتجر كله، وليس اليوم فقط.
- جميع الاستعلامات وفق اتصال المستخدم وتصفية store_id. المؤشرات المفقودة لا تعرض صفراً مصطنعاً.

المعاينة /design-preview/advanced-dashboard تطوير فقط، بيانات توضيحية، حالات ?state=empty و?state=error. تُحجب في بناء الإنتاج.

التحقق: TypeScript واختبارات الحساب الأربعة نجحت، واستعلامات التكامل قراءتها فقط نجحت دون تعديل البيانات. معاينة سطح المكتب 1440 والهاتف 390 لا تتجاوز عرض الشاشة. ESLint غير مهيأ في المشروع (عرض معالج إعداد)، ولم نغيّر إعداداته. لم يتم النشر أو تنفيذ معاملات مالية.

المتبقي وفق تقسيم المستخدم: POS ثم إنشاء وعرض وقائمة فواتير المبيعات.
