# الخطوة 8 — واجهة نقطة البيع

تنفيذ محلي بتاريخ 2026-10-01، دون نشر أو إنشاء معاملات تجريبية في قاعدة المتجر.

## التنفيذ

- كتالوج متجاوب بثلاثة أعمدة مكتبية وعمودين للهاتف، السعر والكميات والإضافة المباشرة، منع إضافة الصنف النافد.
- البحث بالاسم وSKU والباركود؛ Enter لإضافة تطابق رمز واحد، وF2 للتركيز على البحث.
- قراءة الدليل والتصنيفات على صفحات لتجاوز حد القراءة الافتراضي، وإظهار فشل التحميل بوضوح.
- سلة بكميات مقيدة بالمخزون، تسديد نقدي أو على الحساب، مبلغ مستلم وباقٍ نقدي. الدفعة المسجلة نقداً تساوي إجمالي البيع؛ النقد الزائد يمثل الباقي ولا يزيد إيراد الفاتورة.
- تعليق سلة واحدة في sessionStorage لكل متجر، استعادة مع مراجعة وجود المنتجات والكميات الحالية، وحذف المعلقة عند الحاجة. التعليق لا ينشئ فاتورة ويستمر في جلسة التبويب فقط.
- طي الأثر المحاسبي التقديري، وحماية الإرسال المتكرر أثناء الطلب وبعد صدور الإيصال حتى بدء بيع جديد.
- التصميم الجديد مفعّل لمسار /dashboard/pos، والتحقق المشترك يشمل نموذج الطلب القديم أيضاً.

## التحقق

- نجح npm run build وفحص TypeScript.
- نجحت 3 اختبارات في tests/pos-cart.test.cjs للكميات وحدود المخزون، حساب الباقي، والبحث.
- تحقق متصفح بمعاينة معطلة الحفظ: 2 كابل ×35 وشاحن ×90 =160، المستلم 200 والباقي 40؛ تعليق واستعادة السلة؛ رفض مستلم 150؛ إضافة بالباركود 1000.
- تحقق قراءة فقط لأعمدة المنتجات والتصنيفات المنشورة؛ لا يمثل اختبار صلاحيات RLS لأنه يستخدم عميل الفحص الإداري.
- هاتف 390 بكسل: عرض المستند 390 دون تجاوز أفقي. الصور: pos-desktop.jpg وpos-mobile.jpg.
- معاينة التطوير: /design-preview/pos، غير متاحة في الإنتاج. تستخدم بيانات توضيحية وصوراً بديلة عند عدم وجود صورة منتج.

## القيود

- الشيك والمختلط والتحويل البنكي معطلة في هذه الواجهة؛ لا تجمع تفاصيلها المالية المطلوبة بعد.
- مسار الحفظ الحالي /api/orders/create لم يتغير: لا تقدم هذه المرحلة ضمان معاملة ذرية أو منع التكرار على الخادم، ولم يختبر الحفظ الحقيقي أو الطباعة المادية أو جهاز ماسح فعلي.
- يستخدم الحفظ الصندوق الافتراضي؛ لم يضف اختيار صندوق غير مربوط بالخادم. مسار API الحالي يعتمد ملكية المتجر، وتحتاج صلاحيات الموظفين مراجعة مستقلة.
- الاستعادة تتحقق من المخزون المحمل حالياً، وتحتفظ بأسعار السلة؛ يلزم مراجعتها قبل الإتمام. لا تحجز المخزون.
